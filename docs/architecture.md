# 跨境支付监管助手 - 系统架构

## 1. 系统概述

跨境支付监管助手是一个基于法规知识库的智能咨询系统，旨在帮助用户快速获取跨境支付相关的监管信息和合规指导。系统采用模块化设计，包括法规知识库、法规检索服务、LLM集成模块、API服务和前端界面等核心组件。

## 3. 核心组件

### 3.1 法规知识库

法规知识库是系统的基础，包含结构化的法规JSON文件，每个文件包含法规的元数据、分类信息、章节条款、实施细则和风险等级等信息。

**技术实现：**
- 使用JSON格式存储法规数据
- 按照统一的结构组织法规内容
- 支持多维度的法规分类和标签

**主要文件：**
- `data/regulations/SAFE-2023-15.json`（个人外汇管理办法）
- `data/regulations/SAFE-2022-29.json`（支付机构跨境外汇支付业务试点指导意见）
- `data/regulations/SAFE-2023-08.json`（跨境电子商务外汇管理办法）

### 3.2 法规检索服务

法规检索服务负责根据用户查询，从法规知识库中检索相关法规条款，并返回匹配结果。

**技术实现：**
- MVP版本使用关键词匹配
- 未来计划实现基于向量的语义搜索

**主要文件：**
- `regulation_service.js`

### 3.3 LLM集成模块

LLM集成模块负责调用大型语言模型，根据检索到的法规内容生成专业的监管解答。

**技术实现：**
- MVP版本使用模拟版DeepSeek API
- 未来计划集成Claude 3.7 Sonnet模型

**主要文件：**
- `deepseek_integration.js`

### 3.4 API服务

API服务是系统的核心，负责处理用户请求，协调各个模块的工作，并返回最终结果。

**技术实现：**
- 使用Express框架
- 提供RESTful API
- 支持静态文件服务

**主要文件：**
- `api_service.js`

### 3.5 前端界面

前端界面是用户与系统交互的窗口，提供简洁直观的用户体验。

**技术实现：**
- 使用原生HTML/CSS/JavaScript
- 响应式设计
- 支持自然语言提问

**主要文件：**
- `public/index.html`
- `public/styles.css`
- `public/script.js`

## 4. 数据流

1. 用户在前端界面输入查询
2. 前端通过API发送查询请求
3. API服务接收请求，调用法规检索服务
4. 法规检索服务从法规知识库中检索相关法规
5. API服务将检索结果和用户查询发送给LLM集成模块
6. LLM集成模块生成专业解答
7. API服务将解答和相关法规返回给前端
8. 前端展示解答和相关法规

## 5. 部署方案

### 5.1 本地部署

```bash
# 安装依赖
npm install

# 启动服务
node api_service.js
```

### 5.2 Docker部署

```bash
# 构建镜像
docker build -t cross-border-payment-assistant .

# 运行容器
docker run -p 3001:3001 cross-border-payment-assistant
```

### 5.3 Docker Compose部署

```bash
# 启动服务
docker-compose up -d
```
